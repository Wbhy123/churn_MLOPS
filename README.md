# Churn Prediction – MLOps avec Prefect

## Description

Ce projet consiste à mettre en place un pipeline MLOps pour un modèle de prédiction du Customer Churn, en utilisant Prefect pour l'orchestration et le suivi des différentes étapes du pipeline.
